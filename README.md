# 📊 AluraStoreBr – Análise de Dados de Vendas

Este projeto apresenta uma análise exploratória de dados (EDA) das vendas da loja fictícia **AluraStoreBr**, abordando desde o faturamento até o desempenho de produtos e lojas.

## 🔍 Objetivo

Realizar uma análise detalhada das vendas para identificar padrões, oportunidades e pontos de melhoria, utilizando Python e bibliotecas de análise de dados.

## 📁 Estrutura do Projeto

- **Importação dos dados**: Leitura dos arquivos e preparação do ambiente.
- **Análise do faturamento**: Avaliação do total vendido por período.
- **Vendas por categoria**: Identificação das categorias mais vendidas.
- **Avaliação das lojas**: Análise das notas médias dadas pelos clientes.
- **Produtos mais e menos vendidos**: Comparação de desempenho entre produtos.
- **Frete médio por loja**: Estudo sobre os custos logísticos.
- **Relatório final**: Conclusões gerais e insights obtidos.

## 🛠️ Tecnologias Utilizadas

- Python 3
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Resultado Esperado

Oferecer uma visão clara e visual dos dados de vendas, auxiliando na tomada de decisões estratégicas para a loja.
